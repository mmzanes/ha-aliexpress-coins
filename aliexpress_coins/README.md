# AliExpress Coins

Collect your daily AliExpress coins automatically from Home Assistant.

- Log in once through a phone-sized browser in the Home Assistant sidebar (noVNC over ingress).
- Trigger the daily check-in from any automation with `hassio.addon_stdin`.
- Follow the result in `sensor.aliexpress_coins`, and get a notification when the login expires.

Unofficial. This add-on has no connection to AliExpress or Alibaba.
